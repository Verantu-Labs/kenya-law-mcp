# Reporting a vulnerability

Please report security vulnerabilities through [GitHub Private Vulnerability Reporting](https://github.com/Verantu-Labs/kenya-law-mcp/security/advisories/new).

Include the affected commit or deployment, reproduction steps, expected and observed behavior, and demonstrated impact. Use synthetic data and redact credentials or private material. Keep exploit details out of public issues while the report is investigated.

A public issue about finding a reporting channel does not establish that the underlying vulnerability has been fixed. Repository fixes, deployed changes and client acceptance must be verified separately.
